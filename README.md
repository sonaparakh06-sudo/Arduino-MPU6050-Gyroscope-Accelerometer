MPU6050-Based Inertial Measurement and Orientation Tracking System

A progressive embedded systems project using the MPU6050 accelerometer and gyroscope to estimate orientation, process motion data, and visualise sensor measurements using Python.

Project Overview

This project explores inertial measurement and orientation tracking using an MPU6050 sensor interfaced with an Arduino Uno.

The development is divided into three stages, beginning with raw sensor acquisition and progressing towards orientation estimation and real-time data visualisation.

Additional components, including an SG90 servo motor, HC-SR04 ultrasonic sensor and I2C LCD, are incorporated into the integrated platform prototype.

Development Stages

Stage 1: Raw Sensor Data Acquisition

Objective: Interface the MPU6050 with Arduino Uno and acquire raw accelerometer and gyroscope measurements.

Implementation:

- Established I2C communication between Arduino Uno and MPU6050.
- Initialised the sensor and verified its connection.
- Retrieved acceleration values along the X, Y and Z axes.
- Retrieved angular velocity readings along the X, Y and Z axes.
- Transmitted sensor readings through the Serial Monitor.

Concepts explored:

- I2C communication
- Accelerometer and gyroscope fundamentals
- Sensor interfacing
- Serial communication

Stage 2: Tilt Estimation and Sensor Fusion

Objective: Calculate the platform's orientation using accelerometer and gyroscope measurements.

Part A — Accelerometer-based tilt estimation:

- Converted raw accelerometer measurements into acceleration values.
- Calculated roll and pitch angles using trigonometric functions.
- Used gravity as a reference for estimating sensor orientation.

Part B — Gyroscope integration and complementary filter:

- Converted raw gyroscope readings into angular velocity.
- Implemented gyroscope bias calibration.
- Integrated angular velocity over time to estimate angular displacement.
- Combined accelerometer and gyroscope estimates using a complementary filter to obtain more stable orientation measurements.

Mathematical concepts:

- Trigonometry and inverse tangent functions
- Angular velocity and angular displacement
- Numerical integration
- Sensor fusion

Stage 3: Python-Based Data Visualisation

Objective: Develop a Python application to visualise sensor measurements and platform behaviour.

Implementation:

- Read serial data generated by the Arduino.
- Parsed roll, pitch, servo angle and distance measurements.
- Used Matplotlib to generate continuously updated graphs.
- Visualised roll and pitch over time.
- Plotted servo position and ultrasonic distance.
- Created an animated representation of the tilted sensor board and platform.

Python libraries:

- PySerial
- Matplotlib
- Collections
- Math
- Regular Expressions

The visualiser supports:

- Live serial input from a physical Arduino.
- Replaying previously recorded serial logs.
- Synthetic demo data for testing.
